# Contributing / 参与贡献

Issues and pull requests are welcome. Before submitting a change:

1. Keep the local-only security boundary intact.
2. Run `go test ./...` and `go vet ./...`.
3. Update user-facing Chinese and English documentation together.
4. Do not commit cookies, downloaded media, build outputs, or personal data.

欢迎提交 Issue 和 Pull Request。提交改动前请确保：

1. 不破坏“仅本机访问”的安全边界；
2. 运行 `go test ./...` 与 `go vet ./...`；
3. 同步更新中英文用户文档；
4. 不提交 Cookie、下载内容、构建产物或个人数据。
